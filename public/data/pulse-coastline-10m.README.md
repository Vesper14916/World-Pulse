# World Pulse detailed coastlines

Source: Natural Earth 1:10m coastline, public domain.
https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-coastline/
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_coastline.geojson

Downloaded 2026-09-22. Douglas-Peucker simplified at 0.015 degrees for regional display; original feature topology and dateline segments preserved. Displayed from zoom 4. Geographic context only, not a navigational chart.

Additional land polygons: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_land.geojson (Natural Earth public domain). Simplified at 0.01 degrees, coordinates rounded to 4 decimal places; rings smaller than the simplification threshold omitted. Land and coastline are lazy-loaded at zoom 4 so overview startup does not download regional detail.
